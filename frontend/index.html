How it works

Upload, adjust, download.

Every tool follows the same calm four-step flow, from file to finished result.

  1. 01

    Choose a tool

    Pick the utility that matches your task from the catalog. Each tool page explains what it does and which files it accepts.

  2. 02

    Upload your file

    Drag files onto the page, drop them in the zone, or browse from your computer. Supported formats and size limits are always shown.

  3. 03

    Adjust the settings

    Fine-tune quality, output format, dimensions and metadata. See a live hint of what each option does before you commit.

  4. 04

    Download the result

    Inspect the output — original vs. result, file size and savings — then save the file or start another job.

Local processing

Your files stay on your computer.

The application runs on your machine. When Utils-tool runs locally, uploads are processed by the local Python server and stored temporarily on disk while they are being processed. Files are never sent to an external service in the local deployment, and the server never reaches the network for processing.

Temporary files live in the configured storage directory and are cleaned up automatically after each job, so nothing accumulates on your disk.

No account Nothing to sign up for. Just open the app and start working.
No database Temporary state lives on disk in your storage directory.
No cloud upload All processing happens on your machine.

Questions

Frequently asked questions.

What is Utils-tool?
A free, local-first collection of file utilities. Compress, convert, edit, remove backgrounds, process PDFs and analyze files in your browser.
Does Utils-tool work offline?
The Python backend runs on your machine. When started locally, all processing and storage happen on your computer — no internet connection is required to use the tools.
Where are my files stored?
Uploaded files are written to a temporary local directory while they are being processed and are cleaned up automatically. They are never sent to an external service in the local deployment.
What file formats are supported?
Images: JPG, PNG, WebP and AVIF. PDFs. SVG, ZIP and other common file types. Each tool lists the formats it accepts.
Can I process multiple files at once?
Yes — most tools support batch processing. The per-tool page shows the exact limit.
Can I control compression quality?
Yes. Image and PDF tools expose quality sliders, output format, target file size and metadata options.
Is Utils-tool free?
Yes. There are no paid tiers and no account is required.
Is there a browser extension or desktop app?
Utils-tool runs as a local web application. Start it with start.sh and open it in Chrome or any modern browser.

Ready to get started?
